Details and fix

Indirect access to variables, properties and methods will be evaluated strictly in left-to-right order since PHP 7.0. Use curly braces to remove ambiguity. (PHP 7.0 meaning change: code that runs on PHP 7 or 8 today already has the new meaning, so the upgrade changes nothing)

The plugin uses a complex way of naming values that PHP 7.0 and later read in a different order. The code may do something different from what was intended. What to do: Test the plugin after upgrading. For your developer: add curly braces to make the intended order explicit.
