What this means for you

The plugin should keep running on PHP 8.4, but it uses features PHP has deprecated. Deprecations don't stop your site today; they can become errors in a later PHP version, and they may fill your error log.

❌ ErrorUses old curly-bracket syntax
Details and fix

In bundled library code (may only break if this code runs): Curly brace syntax for accessing array elements and string offsets has been deprecated in PHP 7.4 and removed in PHP 8.0. Found: $subProp[1]{0}

The plugin reads parts of lists or text using curly brackets { }. PHP 8.0 and later cannot read this code, so the page stops with an error. What to do: Update the plugin or theme. If the newest version still has this, replace the plugin. For your developer: use square brackets [ ] instead.
