ℹ️ GuardedUses a word that PHP now reserves
Details and fix

'resource' is a soft reserved keyword as of PHP version 7.0 and should not be used to name a class, interface, trait or enum or as part of a namespace (class declaration) (resource has been a soft reserved name since PHP 7.0 and naming a class Resource never raises an error, so nothing changes on newer PHP)

The plugin names a piece of its code with a word that newer PHP versions use as a keyword (for example 'enum', 'match' or 'readonly'). PHP cannot read this code and the page stops with an error. What to do: Update the plugin or theme. If no update fixes it, ask its developer or replace the plugin. For your developer: rename the class, function or constant.
