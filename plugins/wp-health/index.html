❌ ErrorJoins text in a way PHP 8 rejects
Details and fix

Passing the $glue and $pieces parameters in reverse order to implode has been deprecated since PHP 7.4 and is removed since PHP 8.0; $glue should be the first parameter and $pieces the second

The plugin joins a list into text using an old argument order. PHP 8.0 and later reject this order and the page stops with an error. What to do: Update the plugin or theme. If no update fixes it, ask its developer. For your developer: call implode($separator, $array).
