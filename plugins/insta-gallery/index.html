What this means for you

The plugin should keep running on PHP 8.4, but it uses features PHP has deprecated. Deprecations don't stop your site today; they can become errors in a later PHP version, and they may fill your error log.

SeverityProblemWhere
⚠️ WarningOld way of writing optional values (PHP 8.4 warning)
Details and fix

Implicitly marking a parameter as nullable is deprecated since PHP 8.4. Update the type to be explicitly nullable instead. Found implicitly nullable parameter: $request.

The plugin writes optional values in a way PHP 8.4 has started to warn about. The site keeps working; PHP only writes notices to the error log. This is one of the most common findings and is not urgent. What to do: No action needed before upgrading. Keep the plugin updated so the developer can tidy this up before a future PHP version removes it. For your developer: change 'Type $x = null' to '?Type $x = null'.
