Implicitly marking a parameter as nullable is deprecated since PHP 8.4. Update the type to be explicitly nullable instead. Found implicitly nullable parameter: $dispatcher.

The plugin writes optional values in a way PHP 8.4 has started to warn about. The site keeps working; PHP only writes notices to the error log.
