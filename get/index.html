Get the free LeapCheck plugin

Check every plugin and theme on your WordPress site against PHP 8.3, 8.4 and 8.5 in seconds. Free, and it sends no site data.

Download

Download LeapCheck (.zip)

The plugin is currently in review for the WordPress.org plugin directory. Until it's listed there, install it from this download. It's the same code, open source on GitHub.

How to install

  1. In your WordPress admin, go to Plugins → Add New → Upload Plugin.
  2. Choose the downloaded .zip file and click Install Now, then Activate.
  3. Open Tools → LeapCheck and click the button to check your plugins.

What it does, and what it doesn't

  • Shows, for each installed plugin and theme, whether it is compatible with PHP 8.3, 8.4 and 8.5, with the problems found and what to do.
  • Warns about old libraries bundled inside plugins, and about plugins that bundle different versions of the same library.
  • Nothing is fetched until you agree. It only looks up public plugin names and versions; no site address, users or content are sent. See Privacy.
  • Results come from automated static analysis: a strong guide, not a guarantee. Always test an upgrade on a staging copy first.
